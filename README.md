# florida-healthandlifeinsurance

Materiales y plataforma de estudio para el examen de licencia de **Agente de Salud y Vida
de Florida** (incluye anualidades y contratos variables, licencia 2-15).

| Carpeta | Contenido |
| --- | --- |
| [`simulador/`](simulador/) | Simulador de examen en español (React + TypeScript + Vite), con banco validado de 250 preguntas. |
| [`spanish-research-dossiers/`](spanish-research-dossiers/) | Expedientes de investigación en español, uno por dominio del esquema oficial. |
| `121003.pdf` | Esquemas de Contenido del Examen de Seguros de Florida, vigentes desde el 1 de enero de 2026. |

Consulta [`simulador/README.md`](simulador/README.md) para instrucciones de ejecución,
estructura del banco de preguntas y funcionalidades.
